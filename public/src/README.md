# Logo

Coloque aqui o arquivo da logo (ex.: `logo.svg` ou `logo.png`).

- Formato preferido: SVG (escala bem em qualquer tema/tamanho). Se for PNG, mande também uma versão `@2x` para telas retina.
- O selo atual no cabeçalho (`.marca-selo`, em `public/index.html`) tem 28×28px — pensando nisso, uma logo quadrada ou com essa proporção encaixa sem redesenhar o layout.
- Depois de colocar o arquivo aqui, é só pedir para eu trocar o `<svg class="marca-selo">` do cabeçalho (`public/index.html`) por `<img src="src/logo.svg" class="marca-selo" alt="...">` — ou usar como favicon, se preferir.

**Nota:** esta pasta fica dentro de `public/`, então por padrão só é servida para quem já está logado (mesma regra do resto do painel — só `/login`, `/login.html`, `/login.js` e `/styles.css` são públicos). Se quiser a logo também na tela de login, avise que eu libero o caminho certo.
